# 🚀 AI 스마트 견적서 자동 생성기

사용자가 음성으로 말하거나, 두서없이 작성된 메모/이메일/메신저 대화 텍스트를 입력하면 **OpenRouter AI 모델(DeepSeek, Gemini 등)**이 이를 분석하여 표준 견적서 양식(`견적서양식.pdf` 기반)에 자동으로 정밀 입력해 주는 **스마트 견적서 웹 애플리케이션**입니다.

API Key는 로컬 환경변수(`.env`)로 안전하게 관리되어 외부에 노출되지 않습니다.

---

## 🌟 주요 특징

1. **안전한 환경변수 기반 AI 연동**
   - API Key는 클라이언트 코드나 Git에 노출되지 않고, 로컬 `.env` 파일에서 안전하게 관리됩니다.
   - Node.js 내장 모듈 기반 프록시 서버를 탑재하여 추가 라이브러리(`node_modules`) 설치 없이 가볍고 빠르게 동작합니다.

2. **AI 기반 견적 항목 자동 매핑**
   - 메일이나 메신저 글, 대화 녹음 스크립트를 입력하면 수신자, 견적명, 일자, 품목, 규격, 수량, 단가, 부가세 여부, 참조사항을 완벽한 JSON 구조로 변환하여 자동 기입합니다.
   - 안정적인 고성능 모델 지원: `DeepSeek V3`, `Gemini 2.5 Flash`, `Llama 3.3 70B` 등.

3. **Web Speech API 실시간 음성 인식 (STT)**
   - 브라우저 내장 음성 인식 기능을 활용하여 마이크 버튼만 누르면 한국어 음성을 실시간 텍스트로 받아 적고 즉시 AI 변환을 실행할 수 있습니다.

4. **견적서 양식 완벽 재현 & 실시간 자동 연산**
   - 제공된 `견적서양식.pdf`의 레이아웃, 헤더, 표 서식, 하단 소계 및 참조사항을 정밀하게 구현.
   - 수량 × 단가 = 공급가액, 부가세 10%, 총합계 실시간 연산.
   - 견적금액 한글 표기 자동 변환 (예: `일금 삼백삼십만 원정 (₩3,300,000)`).
   - 모든 항목은 클릭하여 인라인 타이핑 및 행 추가/삭제 가능.

5. **인쇄 및 PDF 저장 지원**
   - 우측 상단 **[인쇄 / PDF 저장]** 버튼을 누르거나 `Ctrl + P`를 누르면 AI 입력 패널은 자동으로 숨겨지고 깔끔한 A4 규격 1장 견적서로 인쇄 또는 PDF 저장이 가능합니다.

## 📁 파일 구조

```
견적서/
├── .env              # OpenRouter API Key 및 포트 설정 (Git 제외)
├── server.js         # Node.js 경량 로컬 서버 & 프록시 (Zero-dependency)
├── start.bat         # 윈도우 원클릭 서버 실행 배치 파일
├── index.html        # 메인 웹 애플리케이션 화면
├── style.css         # 모던 다크 UI + A4 종이 시뮬레이션 + 인쇄 전용 CSS
├── app.js            # OpenRouter 연동, Web Speech STT, 견적서 연산 로직
├── package.json      # 프로젝트 설정 및 npm scripts
├── 견적서양식.pdf     # 원본 참조 견적서 양식
└── README.md         # 프로젝트 안내 문서
```

## 🚀 사용 방법

### 1. 환경변수 설정 (`.env`)
프로젝트 폴더 내 `.env` 파일에 발급받은 OpenRouter API Key를 입력합니다:
```env
OPENROUTER_API_KEY=sk-or-v1-your-key-here
PORT=3000
```

### 2. 실행하기
다음 중 편한 방법으로 실행합니다:
- **방법 A (윈도우 원클릭)**: `start.bat` 파일을 더블클릭합니다.
- **방법 B (터미널)**: 터미널에서 `node server.js` 또는 `npm start` 입력 후 브라우저에서 `http://localhost:3000` 접속

### 3. 견적서 자동 완성하기
- **음성 입력**: 마이크 버튼(🎙️)을 누르고 견적 내용을 자유롭게 말합니다.
- **텍스트 입력**: 이메일, 카카오톡 메시지, 메모 등을 텍스트 상자에 붙여넣거나 상단의 [샘플 불러오기]를 클릭합니다.
- **[✨ AI 견적서 자동 완성하기]** 버튼을 클릭하면 견적서 양식에 알맞게 자동 입력됩니다.

### 4. 검토 및 인쇄 / PDF 저장
- 우측 견적서에서 필요시 세부 내용을 직접 타이핑하여 수정하거나 행을 추가/삭제합니다.
- 상단 **[인쇄 / PDF 저장]** 버튼을 눌러 인쇄하거나 PDF로 저장합니다.
