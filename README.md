# 🚀 AI 스마트 견적서 자동 생성기

사용자가 음성으로 말하거나, 두서없이 작성된 메모/이메일/메신저 대화 텍스트를 입력하면 **OpenRouter AI의 초저비용 고성능 모델**이 이를 분석하여 표준 견적서 양식(`견적서양식.pdf` 기반)에 자동으로 정밀 입력해 주는 **100% 프론트엔드 정적 웹 애플리케이션**입니다.

---

## 🌟 주요 특징

1. **AI 기반 자동 매핑 (OpenRouter API)**
   - 메일이나 메신저 글, 대화 녹음 스크립트를 입력하면 공급받는 자, 견적명, 일자, 품목, 규격, 수량, 단가, 부가세 여부, 참조사항을 완벽한 JSON 구조로 변환하여 자동 기입합니다.
   - 가성비 및 초고속 모델 기본 지원: `Google Gemini 2.0 Flash`, `Google Gemini Flash 1.5`, `DeepSeek-V3`, `Mistral Small` 등.

2. **Web Speech API 실시간 음성 인식 (STT)**
   - 브라우저 내장 음성 인식 기능을 활용하여 마이크 버튼만 누르면 한국어 음성을 실시간 텍스트로 받아 적고 즉시 AI 변환을 실행할 수 있습니다.

3. **견적서 양식 완벽 재현 & 실시간 자동 연산**
   - 제공된 `견적서양식.pdf`의 레이아웃, 헤더, 표 서식, 하단 소계 및 참조사항을 정밀하게 구현.
   - 수량 × 단가 = 공급가액, 부가세 10%, 총합계 실시간 연산.
   - 견적금액 한글 표기 자동 변환 (예: `일금 삼백삼십만 원정 (₩3,300,000)`).
   - 모든 항목은 클릭하여 인라인 타이핑 및 행 추가/삭제 가능.

4. **100% 프론트엔드 (HTML/CSS/JS)**
   - **파이썬이나 백엔드 서버가 전혀 필요 없습니다.**
   - 브라우저에서 `index.html` 파일을 더블클릭하여 바로 실행하거나, GitHub Pages / Vercel / Netlify 등에 그대로 업로드하여 배포할 수 있습니다.
   - API Key는 외부 서버가 아닌 사용자의 브라우저(`localStorage`)에만 안전하게 저장됩니다.

5. **인쇄 및 PDF 저장 지원**
   - 우측 상단 **[인쇄 / PDF 저장]** 버튼을 누르거나 `Ctrl + P`를 누르면 AI 입력 패널은 자동으로 숨겨지고 깔끔한 A4 규격 1장 견적서로 인쇄 또는 PDF 저장이 가능합니다.

---

## 📁 파일 구조

```
견적서/
├── index.html        # 메인 웹 애플리케이션 화면
├── style.css         # 모던 다크 UI + A4 종이 시뮬레이션 + 인쇄 전용 CSS
├── app.js            # OpenRouter API 연동, Web Speech STT, 견적서 연산 로직
├── 견적서양식.pdf     # 원본 참조 견적서 양식
└── README.md         # 프로젝트 안내 문서
```

---

## 🚀 사용 방법

1. **실행하기**:
   - `index.html` 파일을 더블클릭하여 크롬, 엣지(Edge) 등 최신 웹 브라우저에서 실행합니다.

2. **API Key 설정**:
   - 상단 헤더의 **[API 설정]** 버튼(⚙️)을 클릭합니다.
   - [OpenRouter Keys](https://openrouter.ai/keys)에서 발급받은 API Key를 입력하고 저장합니다.
   - 원하는 모델(기본: `Google: Gemini 2.0 Flash` 추천)을 선택합니다.

3. **견적서 자동 완성하기**:
   - **방법 A (음성 입력)**: 마이크 버튼(🎙️)을 누르고 마이크에 대고 견적 관련 내용을 자유롭게 말합니다.
   - **방법 B (텍스트 붙여넣기)**: 의뢰인과 주고받은 메일, 카카오톡 메시지, 메모 등을 텍스트 상자에 붙여넣거나 상단의 [샘플 불러오기]를 클릭합니다.
   - **[✨ AI 견적서 자동 완성하기]** 버튼을 클릭하면 견적서 양식에 알맞게 자동 입력됩니다.

4. **검토 및 인쇄 / PDF 저장**:
   - 우측 견적서에서 필요시 세부 내용을 직접 타이핑하여 수정하거나 행을 추가/삭제합니다.
   - 상단 **[인쇄 / PDF 저장]** 버튼을 눌러 인쇄하거나 PDF로 저장합니다.
